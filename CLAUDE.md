# Sunrise Point demo video

This folder holds a static website redesign for The Inn at Sunrise Point and the
brief for turning it into a demo video. The full brief is in PROMPT.md: read it
before doing anything.

- `site/` is the finished website mockup. Treat its copy, prices, placeholders
  and photos as final; fix only rendering bugs, and say what you changed.
- Write all generated files to `out/`. Keep scratch work (frames, temp clips) in
  `out/tmp/` and delete it once the videos are verified.
- Brand colors: deep bay #1B2A33, sunrise gold #D49A2E, sea fog #F2F3EF,
  cream text #EEF1EC. Fonts: Italiana (headlines), Jost (text), from Google Fonts.
